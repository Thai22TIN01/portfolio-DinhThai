Về tôi

Mình là Thái, sinh viên năm 4 ngành CNTT Trường đại học Nam Cần Thơ

Trong suốt hành trình học tập, mình đã thực hành và tham gia xây dựng nhiều dự án từ quy mô demo đến sản phẩm báo cáo thực tế, giúp củng cố nền tảng lập trình và tư duy phát triển phần mềm. Hiện tại, mình đang tập trung sâu vào thiết kế giao diện web cá nhân (portfolio) với các công nghệ hiện đại.

Hiện tại tập trung vào:

  • • Dùng HTML, CSS, JavaScript thuần
  • • Làm layout responsive (desktop → mobile)
  • • Biết React để chia component, render dữ liệu
  • • Dùng TailwindCSS / CSS custom để tạo UI hiện đại

Frontend

React - Next.js - TypeScript - TailwindCSS - Framer Motion - GSAP
